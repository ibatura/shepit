The first tagged version of Shepit. It holds everything built so far: local dictation in Ukrainian and English, meeting transcripts for Teams, Zoom and Google Meet, the offer to record when a call starts, and the main window (Home, Meetings, Dictations, Dictionary, Statistics, People, Settings) with voices.

New in this version:

- **Import names:** in a meeting, Import names… reads the `.vtt` that Teams or Zoom saved of the call, finds where it sits in the meeting and offers each person's name; Apply names names them, and merges two people of one voice. Nothing of the file is kept.
- **About Shepit** in the menu: the version and the commit it was built from.
- Hints on hover show at once.
